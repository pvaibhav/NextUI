# v6.15.0-pvaibhav.3

Hotfix for v6.15.0-pvaibhav.2.

- Fix games crashing on launch. In v6.15.0-pvaibhav.2, every emulator closed immediately, before the game loaded.

If you installed v6.15.0-pvaibhav.2, update to this release. On an existing fork install, open **Updater (pvaibhav)** and choose **Quick Update**.

[Installation and update guide](https://nextui.loveretro.games/usage/#getting-started).
